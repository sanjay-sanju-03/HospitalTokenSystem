=== INSTALLATION ===

To install all dependencies, run:
  npm install

Or if using yarn:
  yarn install

=== RUNNING THE PROJECT ===

Development:
  npm run dev              # Start development server (http://localhost:3000)
  npm run dev:with-socket  # Start dev server with WebSocket support

Production:
  npm run build            # Build for production
  npm run start            # Start production server

Linting:
  npm run lint             # Run ESLint

=== CORE FEATURES BY DEPENDENCY ===

• Next.js (16.1.1)
  - Server-side rendering, API routes, file-based routing
  - App Router for modern page structure
  - Automatic code splitting and optimization

• React (19.2.3)
  - Component-based UI
  - State management with hooks
  - Modern React features

• Bootstrap (5.3.8)
  - Responsive grid system
  - Pre-built components
  - CSS utilities for styling

• SQLite (better-sqlite3)
  - Persistent token storage
  - Queue management
  - Doctor/department data
  - OTP verification

• Socket.io (4.8.3)
  - Real-time queue updates
  - Live notifications
  - WebSocket fallback

• Twilio (5.11.1)
  - SMS notifications for tokens
  - Optional integration (demo mode works without it)

• TypeScript (5)
  - Type safety
  - Better developer experience
  - Catch errors at compile time

=== OPTIONAL INTEGRATIONS ===

SMS Service (Twilio):
  - Create .env.local with:
    TWILIO_ACCOUNT_SID=your_sid
    TWILIO_AUTH_TOKEN=your_token
    TWILIO_PHONE_NUMBER=your_number
  - Without these, SMS runs in demo mode (prints to console)

WebSocket Server:
  - Optional socket-server.ts for real-time updates
  - Alternative to polling (5-second refresh currently used)
